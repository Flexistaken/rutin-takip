                 RUTİN TAKİP

Rutin takip projesi benim pythonda kendimi geliştirdiğim bunu yaparken de rutinlerimi takip edebileceğim projedir.

Takip edilen günlük rutinler: Günlük yazma, Kitap okuma, Spor yapma, Projeyi geliştirmeye devam etme

Repo'yu kimse indirmeyeceği için buraya ne yazsam bilemedim, main.py'yi çalıştırıp bakın!!!

Veri JSON'da tutulacak , örnek : {"2026-09-14": {"journal": true, "reading": false, ...}}

Projenin durumu : V1 olarak geliştirdiğim bu projede sadece rutini yapıp yapmadığım gibi temel şeyler olacak , eğer devam edersem tüm rutinlerin kendilerine özel veri olarak tuttukları şeyler olacak. Mesela spor yapma kısmında kaç push up yaptığım gibi.
